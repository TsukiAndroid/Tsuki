Common questions

What is Tsuki?

Tsuki is a free and open-source Android reader for manga, manhwa, manhua and novels.

Is Tsuki free?

Yes. Tsuki is an open-source project distributed under the GPL-3.0 license.

Which Android versions are supported?

Tsuki's minimum Android version is Android 6.0 (API level 23).

Does Tsuki host manga?

No. Tsuki does not host, store or distribute manga content. It connects to third-party sources.

How many manga sources does Tsuki support?

The project describes more than 1,200 built-in sources. Availability depends on third-party websites and parser compatibility.

Can I add custom sources?

Tsuki includes in-app custom parser support. Compatibility depends on the website and parser.

Does Tsuki support novels?

Yes. Tsuki includes novel-reading support based on work from the Futon project.

Where can I download Tsuki?

The official builds are published on the Tsuki GitHub Releases page.

Still need help?

Visit the GitHub repository for documentation and issue reporting, or join the Tsuki Discord community.

Open source, built for readers.

Tsuki is a reader application, not a manga hosting service. Sources are third-party websites, and availability can change independently of Tsuki.
