A reader built around choice

A flexible manga reader for Android

Tsuki is a free, open-source Android app for reading manga, manhwa, manhua and novels. It brings a broad source library together with customizable reading tools and support for older Android devices.

Reading features

📚

1,200+ built-in sources

Browse supported manga sources through the parser library included with Tsuki. Source availability depends on each third-party website.

🧩

Custom parsers

Add website parsers from inside the app, including alternate mirrors where supported, without waiting for a full app release.

📖

Two reader modes

Choose standard page reading or a webtoon-optimized mode for vertically scrolling comics.

⬇️

Offline reading

Download supported manga for reading when you are not connected to the internet.

🔖

Library tools

Keep track of favorites, reading history and bookmarks, and search using names, genres and filters.

🌙

Performance and comfort

Use performance mode on lower-spec devices and an AMOLED-friendly dark theme. App lock is also supported.

More than manga

Tsuki also includes novel-reading support, plus in-app browsing and support for Keiyoushi extensions. The available experience can vary by source and extension.

Explore the source and parser options, learn about the novel reader, or see Android compatibility.
