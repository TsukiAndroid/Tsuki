More ways to find what you read

Manga sources, parsers and extensions

Tsuki is designed to work with a wide range of third-party manga websites. Its built-in parser library includes more than 1,200 sources, and the app also supports adding custom parsers.

Get TsukiExplore the source code

Built-in source library

Tsuki uses the kotatsu-parsers-redo parser library to connect readers with supported manga, manhwa and manhua websites. The number of available sources can change as websites and parsers are updated.

Add custom parsers

Tsuki includes in-app parser support, allowing users to add a website as a custom source when a compatible parser is available. This can be useful when a site changes its address or offers an alternate mirror.

Custom parser compatibility depends on the website's structure and the parser implementation. Not every website will work automatically.

Keiyoushi extension support

Tsuki also supports Keiyoushi extensions. Extension availability, compatibility and maintenance are managed separately from Tsuki itself.

Important source information

  • Tsuki does not host or distribute manga content.
  • Sources are third-party websites and may become unavailable or change their behavior.
  • Content, language, access rules and availability vary by source.
  • Users are responsible for following applicable laws and each source's terms.
