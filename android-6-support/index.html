Made to support older devices

Manga reading on Android 6.0 and newer

Tsuki supports Android 6.0 and later. Its minimum SDK is API 23, and it includes a performance mode intended to help on lower-spec and older Android devices.

Minimum Android version

Android 6.0+

Tsuki's minimum supported Android version is Android 6.0 (Marshmallow), corresponding to API level 23.

Performance mode

A performance mode is available for low-spec and older Android devices. Actual performance depends on device hardware, Android version, network conditions and the source being used.

Dark theme

Tsuki includes an AMOLED-friendly dark theme for a darker reading interface.

Compatibility notes

Meeting the minimum Android version does not guarantee that every third-party source, extension or feature will work identically on every device. Some sources may require newer browser, TLS or WebView capabilities.

For the latest build and release-specific requirements, check the official releases and project repository.

Open source, built for readers.

Tsuki is a reader application, not a manga hosting service. Sources are third-party websites, and availability can change independently of Tsuki.
